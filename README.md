# 🤖 AI Text Summarizer

A modern, responsive and user-friendly web application that summarizes long text into shorter and meaningful content. It helps users save time by extracting the most important sentences from lengthy paragraphs.

## 📌 Project Overview

The AI Text Summarizer is a web-based application developed using HTML, CSS, and JavaScript. It provides a simple interface where users can enter long text and generate a shorter summary.

The application offers three summary lengths: Short, Medium, and Long. Users can also copy, clear, and download the generated summary.

**Note:** This college mini-project uses a simple sentence-selection algorithm for demonstration purposes. It does not use a trained AI model or an external AI API.

## ✨ Features

## ⚙️ How It Works

1. User enters a paragraph or long text.
2. User selects a summary length.
3. JavaScript processes the input text.
4. The summarization algorithm separates the text into sentences.
5. Important sentences are selected according to the demonstration algorithm.
6. The generated summary is displayed in the output section.
7. Users can copy or download the summary.

## 🧠 Summarization Methodology

This project uses an extractive, rule-based sentence-selection approach.

The application identifies sentences from the original text and selects a portion of them according to the selected summary length.

It is a basic demonstration of text summarization concepts and does not perform advanced semantic understanding.
